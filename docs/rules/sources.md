# Sources

Every rule lists the documents it is based on: mostly vendor documentation, benchmarks and
standards, plus a few advisories, release notes and articles. This page lists all of them, and
the sources of the [trade-offs page](tradeoffs.md), by site and page, with the rules and
trade-off sections that cite each one, so you can see what the rulebook rests on and where to
read further. It is generated by `.github/scripts/check_rules.py --write`; CI fails if it is out
of date.
